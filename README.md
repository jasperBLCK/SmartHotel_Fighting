# SMART HOTEL FIGHTING

Браузерный 2D-файтинг «все против всех» на чистом HTML5 Canvas + JavaScript.
Без фреймворков, без сборки, без бэкенда. Мультиплеер на 2–4 игрока через
PeerJS (WebRTC), топология «звезда»: хост считает физику, клиенты шлют инпут.

## Запуск

Открыть `index.html` через любой статический сервер (или GitHub Pages):

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Открывать по `file://` нельзя — не сработает загрузка модулей и WebRTC.

## GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.
Файл `.nojekyll` уже лежит в корне.

## Управление

| Действие        | Клавиши                    |
|-----------------|----------------------------|
| Движение        | `A` / `D` или `←` / `→`    |
| Прыжок (двойной)| `W`, `↑` или `Space`       |
| Спуск с платформы | `S` / `↓`                |
| Удар рукой      | `J`                        |
| Удар ногой      | `K`                        |
| Блок            | `L` или `Shift`            |

Раскладка общая: каждый играет со своего устройства, клавиатуру делить не нужно.

## Как играть

1. Один игрок жмёт **СОЗДАТЬ ЛОББИ** и получает код комнаты (5 символов).
2. Остальные вводят код и жмут **ПОДКЛЮЧИТЬСЯ** (до 4 игроков всего).
3. Каждый загружает фото — на нём **автоматически находится лицо**, вырезается
   голова и становится головой персонажа. Фото никуда не отправляется на сервер:
   и распознавание, и обрезка идут в браузере, дальше только P2P-канал.
4. Хост может загрузить фото арены (фон) и выбрать лимит киллов.
5. Хост жмёт **НАЧАТЬ БОЙ**.

HP — 100. При обнулении боец гибнет и возрождается через 10 секунд на дальней
от живых игроков точке с полным HP и коротким иммунитетом.

Ничего не сохраняется: ни на сервере, ни в `localStorage` — всё живёт в памяти
до закрытия вкладки.

## Структура

```
index.html      разметка трёх экранов: меню / лобби / бой
css/styles.css  оформление
js/utils.js     математика, сжатие картинок, синтезированный звук, тосты
js/face.js      поиск лица на фото и вырез головы
js/net.js       обёртка над PeerJS: комнаты, рассылка, пинг
js/fighter.js   арена, физика бойца, хитбоксы, скелет и отрисовка персонажа
js/game.js      игровой цикл, авторитетная симуляция хоста, эффекты, рендер
js/ui.js        экраны, лобби, склейка сети и игры
assets/models/  blaze_face_short_range.tflite (225 КБ) — модель детектора лиц
```

## Персонажи

Рисуются кодом, без спрайтов: торс, две руки и две ноги по два сегмента.
Позы задаются целевыми точками кистей и стоп, а локти и колени считает
двухзвенная IK (`solveIK` в `js/fighter.js`) — поэтому стойка, бег, прыжок,
удары и блок выглядят связно и легко правятся.

- Пропорции тела — объект `BODY` (`js/fighter.js`).
- Позы под каждое состояние — метод `Fighter.pose()` там же.
- Оттенки кожи по слотам — массив `SKIN`; цвет игрока идёт на перчатки,
  ботинки, шорты и повязку.

## Распознавание лица

`js/face.js`, цепочка с деградацией — если верхний способ недоступен,
работает следующий, игра не ломается ни при каких условиях:

1. **MediaPipe Tasks Vision** (BlazeFace short-range). Модель лежит в репозитории,
   wasm-рантайм подтягивается с jsDelivr. Даёт рамку лица и 6 ключевых точек.
2. **Нативный `window.FaceDetector`** — есть в части сборок Chrome.
3. **Обрезка по центру верхней трети** кадра.

По глазам считается межзрачковое расстояние `d`: размер черепа ≈ `3.0d`,
центр головы ≈ середина глаз + `0.32d` вниз, а наклон головы выправляется
поворотом по линии глаз. Константы — `SKULL_K`, `CENTER_K` в `js/face.js`.

## Что можно докрутить

- Геометрия арены — `ARENA` в `js/fighter.js` (пол, платформы, точки респавна).
- Баланс — `PHYS` и `ATTACKS` там же (урон, дальность, отбрасывание, кадры).
- Новые удары — добавить запись в `ATTACKS`, бит в `K` и клавишу в `KEYMAP` (`js/game.js`).
- Частота снапшотов и буфер интерполяции — `SEND_EVERY` / `INTERP_MS` в `js/game.js`.

## Известные ограничения

- Сигнальный сервер — публичный брокер PeerJS. Если он лежит, комнаты не создаются.
- Симметричные NAT без TURN-сервера могут не пробиться: в `peerOpts()` (`js/net.js`)
  указаны только STUN — при необходимости добавь свой TURN.
