# SMART HOTEL FIGHTING

Браузерный 2D-файтинг «все против всех» на чистом HTML5 Canvas + JavaScript.
Без фреймворков, без сборки, без бэкенда. Мультиплеер на 2–4 игрока через
PeerJS (WebRTC), топология «звезда»: хост считает физику, клиенты шлют инпут.

## Запуск

Открыть `index.html` через любой статический сервер (или GitHub Pages):

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Открывать по `file://` нельзя — не сработает загрузка модулей и WebRTC.

## GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.
Файл `.nojekyll` уже лежит в корне.

## Управление

У каждого удара своя клавиша, комбинаций нет. Левая рука — движение,
правая — удары: верхний ряд `U I O` это руки, нижний `J K L` — ноги.

| Действие          | Клавиши                  |
|-------------------|--------------------------|
| Движение          | `A` / `D` или `←` / `→`  |
| Прыжок (двойной)  | `W`, `↑` или `Space`     |
| Спуск с платформы | `S` / `↓`                |
| Блок              | `Shift` или `P`          |
| Джеб              | `U`                      |
| Хук               | `I`                      |
| Апперкот          | `O`                      |
| Хай-кик           | `J`                      |
| Лоу-кик           | `K`                      |
| Подсечка          | `L`                      |
| Подколки          | `1` … `5`                |

В прыжке любая клавиша руки даёт удар с воздуха, любая клавиша ноги — дайв-кик.

Раскладка общая: каждый играет со своего устройства, клавиатуру делить не нужно.

## Как играть

1. Один игрок жмёт **СОЗДАТЬ ЛОББИ** и получает код комнаты (5 символов).
2. Остальные вводят код и жмут **ПОДКЛЮЧИТЬСЯ** (до 4 игроков всего).
3. Каждый загружает фото — на нём **автоматически находится лицо**, вырезается
   голова и становится головой персонажа. Фото никуда не отправляется на сервер:
   и распознавание, и обрезка идут в браузере, дальше только P2P-канал.
4. Хост может загрузить фото арены (фон) и выбрать лимит киллов.
5. Хост жмёт **НАЧАТЬ БОЙ**.

HP — 100 (у разных бойцов своё). При обнулении боец падает и возрождается через
10 секунд на дальней от живых точке с полным HP и коротким иммунитетом.

**Выносливость — главная механика.** Тратят её удары и прыжки, а пропущенные
и даже заблокированные удары выбивают дыхание сверх того. Восстанавливается
медленно, в блоке — почти никак. Выдохся: бить нечем, скорость падает на 40%,
боец стоит руки в колени, дышит паром. Спамить удары не выйдет — накажут.

**Блок ломается.** У блока своя прочность, каждый принятый удар её снимает
(тяжёлые — сильнее). Пробили — оглушение на ~0.9 секунды и полная открытость.
Толщина белой дуги показывает, сколько блока осталось.

**Кровь.** Чем ниже HP, тем больше ссадин на лице и корпусе; брызги остаются
пятнами на асфальте, а после нокаута под телом расплывается лужа.

**Подколки.** Клавиши `1`…`5` (или панель в углу мышкой) — облачко над головой
с эмодзи и подписью, которое видят все. Стоит выносливости и имеет откат,
так что дразнить в упор — риск.

Ничего не сохраняется: ни на сервере, ни в `localStorage` — всё живёт в памяти
до закрытия вкладки.

## Структура

```
index.html      разметка трёх экранов: меню / лобби / бой
css/styles.css  оформление
js/utils.js     математика, сжатие картинок, синтезированный звук, тосты
js/face.js      поиск лица на фото и вырез головы
js/net.js       обёртка над PeerJS: комнаты, рассылка, пинг
js/fighter.js   арена, физика бойца, хитбоксы, скелет и отрисовка персонажа
js/game.js      игровой цикл, авторитетная симуляция хоста, эффекты, рендер
js/ui.js        экраны, лобби, склейка сети и игры
assets/models/  модели: детектор лиц (225 КБ) и сегментация силуэта (244 КБ)
```

## Персонажи

Рисуются кодом, без спрайтов: торс, две руки и две ноги по два сегмента.
Позы задаются целевыми точками кистей и стоп, а локти и колени считает
двухзвенная IK (`solveIK` в `js/fighter.js`) — поэтому стойка, бег, прыжок,
удары и блок выглядят связно и легко правятся.

В лобби каждый выбирает бойца из шести: **Пацан, Старшой, Джигит, Борец,
Боксёр, Дворовый**. Отличаются внешним видом (спортивка с лампасами, кожанка,
жилет с папахой, борцовка, майка с бинтами, шапка) и статами — здоровье,
скорость, урон, выносливость, прочность блока, скорость рук.

- Пропорции тела — объект `BODY` (`js/fighter.js`).
- Позы под каждое состояние — метод `Fighter.pose()` там же.
- Персонажи — массив `CHARACTERS`: `look` (одежда, головной убор, оттенок кожи)
  и `st` (статы). Цвет игрока идёт на одежду, кроссовки и лампасы.

## Распознавание лица

`js/face.js`, цепочка с деградацией — если верхний способ недоступен,
работает следующий, игра не ломается ни при каких условиях:

1. **MediaPipe Tasks Vision** (BlazeFace short-range) — рамка лица и 6 ключевых
   точек. Модель лежит в репозитории, wasm-рантайм подтягивается с jsDelivr.
2. **Нативный `window.FaceDetector`** — есть в части сборок Chrome.
3. **Обрезка по центру верхней трети** кадра.

По глазам считается межзрачковое расстояние `d`: размер черепа ≈ `3.15d`,
центр головы ≈ середина глаз + `0.30d` вниз, а наклон головы выправляется
поворотом по линии глаз. Константы — `SKULL_K`, `CENTER_K`.

Дальше **Selfie Segmenter** даёт маску «человек/фон» на этом вырезе — это и есть
силуэт головы вместе с причёской. Маска умножается на «окно головы» (овал
с мягким срезом снизу, чтобы убрать шею и плечи), край размывается и уходит
в альфа-канал. На выходе — PNG с прозрачностью, поэтому в игре видна реальная
форма головы, а не круг. Если сегментация недоступна, остаётся мягкий овал.

## Что можно докрутить

- Геометрия арены — `ARENA` в `js/fighter.js` (пол, платформы, точки респавна).
- Баланс — `PHYS` и `ATTACKS` там же (урон, дальность, отбрасывание, кадры,
  расход выносливости, урон по блоку).
- Персонажи — массив `CHARACTERS`: внешний вид (`look`) и статы (`st`).
- Новые удары — добавить запись в `ATTACKS` и вернуть её имя из `Fighter.pickAttack`.
- Двор рисуется в `drawCourtyard` (`js/game.js`) — если фото арены не загружено.
- Частота снапшотов и буфер интерполяции — `SEND_EVERY` / `INTERP_MS` в `js/game.js`.

## Игра через интернет

Одна сеть не нужна: игроки могут сидеть в разных городах и провайдерах.
Все просто открывают сайт на GitHub Pages, один создаёт лобби, остальные
вводят код. Соединение устанавливается напрямую между браузерами:

- **Сигнальный сервер** — публичный брокер PeerJS, через него участники
  только находят друг друга по коду комнаты.
- **STUN** пробивает обычные домашние NAT — это большинство случаев.
- **TURN** (бесплатные публичные серверы openrelay) включается, когда прямое
  соединение невозможно: мобильный интернет, корпоративная сеть, строгий NAT.
  Тогда трафик идёт через ретранслятор — чуть выше пинг, но игра работает.

Всё это настраивается в `peerOpts()` (`js/net.js`). Публичный TURN бесплатный
и может тормозить под нагрузкой — для стабильности заведи свой (coturn или
metered.ca) и подставь свои `urls` / `username` / `credential`.

## Известные ограничения

- Сигнальный брокер PeerJS публичный: если он недоступен, комнаты не создаются.
- Публичный TURN не даёт гарантий по скорости — см. раздел выше.
